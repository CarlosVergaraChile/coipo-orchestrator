## Uso entre herramientas

GitHub conserva decisiones, enlaces, pruebas y tareas. El índice se puede abrir como Markdown en Obsidian. Los expedientes privados se referencian únicamente en espacios con acceso autorizado. Para recuperar contexto, leer la ficha del proyecto y la evidencia vigente antes de usar conclusiones anteriores.

Usar flujos repetibles para descargar y comparar fuentes, registrar diferencias y ejecutar pruebas. Usar asistentes para resumir cambios y proponer acciones respaldadas. Revisar esas propuestas antes de incorporarlas como decisiones. Conservar la fuente y fecha de cada hallazgo.
